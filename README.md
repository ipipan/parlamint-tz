# Tanzanian parliament proceedings in Parlamint format

**ParlaMint-TZ** is a standardized parliamentary corpus constructed from Tanzanian parliamentary proceedings (Hansards) spanning 2003 to 2025. Comprising 1,642 documents (nearly 300,000 pages and approximately 90 million words) primarily in Swahili with occasional English, it provides a comprehensive resource for large-scale research on political discourse, language use, and multilingual practices. This repository hosts the resulting corpus data in a unified,  the [ParlaMint-compliant](https://clarin-eric.github.io/ParlaMint/) TEI XML format—converted from heterogeneous, unstructured PDF transcripts using a deterministic rule-based pipeline to standardize speaker identification, structural segmentation, and non-speech annotations. The corpus is also accessible via an [online platform](https://parlamint-tz.ipipan.waw.pl/) featuring full-text search, term highlighting, and structured transcript rendering.

See [ParlaMint website](https://www.clarin.eu/parlamint) for the information about the ParlaMint project.
